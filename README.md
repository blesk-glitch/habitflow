# HabitFlow — веб‑помощник для формирования привычек и управления задачами

HabitFlow — это веб‑приложение на Flask, которое помогает пользователям ставить задачи, отслеживать их выполнение и формировать полезные привычки с помощью системы очков. Проект разработан в рамках учебной контрольной работы.

## Возможности

- Регистрация и авторизация пользователей (хэширование паролей, Flask‑Login)
- Создание, редактирование, удаление и выполнение задач
- Приоритеты задач (низкий, средний, высокий)
- Начисление очков за выполненные задачи (геймификация)
- Просмотр списка задач на дашборде
- Календарь задач (или таблица с датами)
- REST API для получения и создания задач (`GET /api/tasks`, `POST /api/tasks`)
- Адаптивный интерфейс на Bootstrap 5
- Загрузка аватара пользователя (опционально, если реализовано)

## Использованные технологии

- **Python 3.12**
- **Flask 2.3.3** и расширения: Flask‑SQLAlchemy, Flask‑Migrate, Flask‑Login, Flask‑WTF
- **SQLite** (база данных)
- **Bootstrap 5**
- **FullCalendar** (опционально для календаря) – в проекте используется таблица
- **Git** для контроля версий
